O.D.I.N = ORBITAL (OR) OBJECT DETECTION AND INTELLIGENCE NODE


*This project uses an Arduino Uno,HC-SR04, servo motor, and buzzer to detect nearby objects and perform automatic control.
*The ultrasonic sensor measures the distance of an object using ultrasonic waves.
*The measured distance is sent to the Arduino for processing and decision making.
*When an object comes within a set distance, the Arduino rotates the servo motor automatically.
*At the same time, the buzzer turns ON to provide an alert indication.
*This system can be used in applications such as automatic doors, smart dustbins, and obstacle detection systems.
